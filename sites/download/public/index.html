Windows

Matches this computer

For 64-bit Windows 10 and 11.

Download for Windows

How to install
  1. Open the file you downloaded.
  2. If Windows says “Windows protected your PC”, choose More info, then Run anyway.
  3. Follow the steps. It installs for your user account only, so it doesn’t ask for an administrator password. World Vitality opens when it finishes.

Mac

Matches this computer

There is one file for each kind of Mac.

Download for Apple chip

Download for Intel

Which Mac do I have?

Choose the Apple menu, then About This Mac. If it says Chip with a name starting “Apple M”, choose Apple chip. If it says Processor with an Intel name, choose Intel.

How to install
  1. Open the file you downloaded, then drag World Vitality into Applications.
  2. Open World Vitality from Applications. If macOS says it can’t check the app for malicious software, close the message and open System Settings, then Privacy & Security.
  3. Scroll to the message about World Vitality and choose Open Anyway. You only do this once. On older versions of macOS, right-click the app and choose Open instead.

Linux

Matches this computer

For 64-bit Linux desktops. It is an AppImage, so it needs no installer.

Download for Linux

How to run it
  1. Make the file runnable: right-click it, open Properties, and allow running it as a program. Or, in a terminal, run chmod +x World-Vitality-*.AppImage.
  2. Double-click the file, or run it from the terminal.
  3. If nothing happens, install your system’s FUSE 2 package (often called libfuse2) and try again.

Android

Matches this phone

For phones and tablets on Android 7 or newer.

Download for Android

How to install
  1. Open this page on your phone and download the file.
  2. Open the downloaded file. Android asks you to allow installing from your browser or Files app; allow it.
  3. If Google Play Protect warns you, choose Install anyway. The app isn’t on Google Play yet, so Play Protect hasn’t seen it before.

iPhone and iPad

There is no app to download. Add the website to your Home Screen.

How to add it
  1. Open the website in Safari.
  2. Tap Share, then Add to Home Screen.
  3. World Vitality opens from your Home Screen like any other app.

Before you open it

These first versions aren’t signed with a publisher certificate yet. The first time you open one, Windows and macOS show a warning that they don’t recognise the publisher. The steps above show how to continue. The app only opens World Vitality; it doesn’t read your files.

Each version lists a checksum for every file. You can check that your download is exactly the file we published.

How to check a download

Run the command for your computer in the folder with the file, then compare the result with the line for that file in the checksums file. The two should match exactly.

Windows (PowerShell)
Get-FileHash .\World-Vitality-Setup-0.1.0.exe -Algorithm SHA256
Mac
shasum -a 256 World-Vitality-0.1.0-arm64.dmg
Linux
sha256sum World-Vitality-0.1.0.AppImage

Use the name of the file you downloaded.

Questions

Is it free to download?

Yes. What you can use inside it depends on your World Vitality plan, the same as on the website.

Why can’t I sign in with Google?

Google doesn’t allow sign-in inside app windows, so the app uses your email and password. If you usually sign in with Google, open the website, choose Forgot password? and set a password first. Then use it in the app.

Do I need to download it again when World Vitality changes?

No. The app shows the live website, so changes to World Vitality appear straight away. You only download again when there is a new version of the app itself, and it will be listed here.

Does it work without internet?

It needs a connection. Without one it shows a short page with a Try again button, and nothing you saved is lost.

What can the app see on my computer?

Very little. The desktop app can’t read your files, turns off the camera, microphone and location, and opens links to other websites in your normal browser. The Android app asks for internet access and nothing else.

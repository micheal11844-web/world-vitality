# Quick check of the live app — 2026-11-11

A read-only look at production, the database and the dependencies, asked for as
"a quick check around the app for a gap". Nothing here needed an emergency; one
real gap was found and fixed (dependencies).

## The dependency fix

`package.json` → `pnpm.overrides` now forces `postcss` ≥ 8.5.23, `nanoid` ≥ 3.3.18
and `source-map-js` ≥ 1.2.2. Next.js 15.5.29, the newest 15.x, still pins PostCSS
8.4.31; the patched PostCSS ships only with Next 16. The advisories are about
processing hostile CSS or source-map files, which this app does not do (it has no
PostCSS config and takes no CSS from users), so there was no urgent exposure.
After the change: `pnpm audit --prod` reports no known vulnerabilities; type check,
lint, formatting, all 684 tests, a production build and the browser tests
(flat map and 3D) pass, and the pages are styled as before.

**Remove the override when moving to Next 16** (it bundles PostCSS 8.5.23).
Run `pnpm audit --prod` now and then; it needs no key.
